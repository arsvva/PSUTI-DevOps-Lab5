# Лабораторная работа №5. Вариант 8
## Управление сериями событий

Веб-приложение для объединения событий в серии, изменения их состава и просмотра входящих в серию событий.

### Технологический стек
*   **Фронтенд:** HTML5, CSS3, JavaScript (Vanilla JS)
*   **Веб-сервер:** Nginx (раздача статики и проксирование API)
*   **Бэкенд:** [kazan-events](https://github.com/nelkor/kazan-events) (Python, FastAPI) - предоставлен в рамках задания
*   **База данных:** PostgreSQL + расширение PostGIS
*   **Инфраструктура:** Docker, Docker Compose

### Требования для запуска
Для запуска приложения на вашем компьютере должны быть установлены:
*   [Docker](https://docs.docker.com/get-docker/)
*   [Docker Compose](https://docs.docker.com/compose/install/)

### Инструкция по запуску

  1. Клонируйте данный репозиторий на свой компьютер:
       git clone https://github.com/arsvva/PSUTI-DevOps-Lab5.git

  2. Перейдите в папку с проектом:
       cd PSUTI-DevOps-Lab5

   3.Запустите приложение одной командой:
       docker compose up -d

  4. Дождитесь, пока контейнеры скачаются и запустятся. Проверить статус командой:
      docker compose ps

### Доступ к приложению
После успешного запуска откройте любой браузер и перейдите по адресу:
http://localhost:8080

### Остановка приложения
Чтобы остановить работу приложения и удалить контейнеры, выполните:
docker compose down

### Структура проекта
* frontend/ - исходный код клиентской части (HTML, JS, стили)

* nginx/ - конфигурация веб-сервера (default.conf)

* compose.yml - файл конфигурации Docker Compose для управления сервисами
